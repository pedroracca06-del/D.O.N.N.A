# PRIME Framework

Status: CURRENT
Authority: owner-approved

PRIME = Position → Relevant Level → Interaction → Market Confirmation → Execution.

## Position
Use 15m/1H/4H primarily for higher-timeframe position and context.

## Relevant Level
Relevant levels may include Asia H/L, London H/L, NY/ORB H/L, PDH/PDL, higher-timeframe highs/lows, validated swing structure, and independently validated liquidity zones.

## Interaction
A level touch alone is never sufficient. Price must interact meaningfully with the level.

## Market Confirmation
Use 5m for meaningful structural confirmation. Do not let 1m noise create the thesis.

## Execution
Use 1m only for execution precision after the higher-level thesis and confirmation exist.
